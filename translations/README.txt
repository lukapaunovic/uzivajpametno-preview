English pages are generated from the Serbian HTML and en.json.
Run from the repository root: python3 scripts/build-english.py
Requires Python package beautifulsoup4.
Keep Serbian source text and its English translation together in en.json when editing copy.
English URLs: /en/, /en/privacy/, /en/resources/, /en/start/, /en/404.html.
The original Serbian brochure and external Instagram posts are not translated. English hero images use a supplied English app screenshot and a localized doctor card.
Noindex stays enabled on both preview languages.
